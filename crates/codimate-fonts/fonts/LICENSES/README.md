# The bundled fonts' licenses

These fonts are compiled into Codimate, so every build and every wheel
carries them. They are not covered by Codimate's MIT license; each keeps its
own, and its text is here.

| font | copyright | license | text |
| --- | --- | --- | --- |
| `NotoSansKhmer-Regular.ttf` | The Noto Project Authors | SIL Open Font License 1.1 | `OFL-1.1-NotoSansKhmer.txt` |
| `DejaVuSansMono.ttf` | Bitstream, Tavmjong Bah; DejaVu changes public domain | Bitstream Vera / DejaVu | `DejaVu.txt` |
| `DroidSansFallbackFull.ttf` | The Android Open Source Project | Apache License 2.0 | `Apache-2.0-DroidSansFallback.txt` |

Each text was fetched from the font's upstream: notofonts/khmer,
dejavu-fonts/dejavu-fonts, and apache.org.
